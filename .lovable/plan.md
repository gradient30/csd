

# 三项功能优化计划

## 1. 封神仪式 —— 一键封神按钮

在 `CeremonyPage.tsx` 的步骤1（问卷页）底部，在"下一步"按钮下方新增一个"一键封神"按钮（次要样式）。

- 点击后弹出确认提示："心诚则灵——亲手填写信息，财神更知你心意。确定要跳过吗？"
- 用户确认后，使用随机默认值自动填充（随机生肖、随机职业、随机愿望、昵称用"有缘人"），直接跳到步骤3生成结果
- 用户取消则关闭弹窗，回到问卷继续填写

## 2. 摇签功能增强

### 2.1 扩充题库

在 `src/lib/ceremony.ts` 的 `RIDDLES` 数组中新增约30道真实可靠的财神文化/传统民俗趣味问答，涵盖：
- 财神典故（文财神/武财神区别、各路财神来历）
- 传统节俗（元宵、春联、门神等）
- 成语谜语（与财富/吉祥相关）
- 生肖知识

### 2.2 "看答案"按钮（每日3次，分享可加10次）

在 `RiddleGame` 组件中：
- 在输入框旁边新增"看答案"按钮（眼睛图标）
- 点击后直接显示正确答案（但不计分，不加香火）
- 使用 localStorage 键 `caishen_hint_date` 和 `caishen_hint_count` 追踪每日使用次数
- 次数用完后按钮灰色不可点，显示"今日已用完"
- 按钮旁显示剩余次数："剩余 X 次"
- 新增"分享朋友圈 +10次机会"按钮，点击后生成分享提示弹窗（模拟分享完成后增加10次额度）

## 3. 迎财神渊源 —— "再学一招"功能

### 3.1 扩充知识库

在 `src/components/OriginCards.tsx` 中，每张卡对应多条真实准确的"学一招"文化知识（每张卡 5-6 条），内容基于真实民俗文献：

- **破五送穷**：如"初五不串门是因为怕把穷带给别人"、"韩愈写过《送穷文》是破五习俗最早文学记录"等
- **五路财神**：如"五路指东南西北中，分管不同方位财运"、"赵公明全称'金龙如意正一龙虎玄坛真君'"等
- **抢路头传统**：如"旧时商家初五开市称'接路头'"、"供品中羊头寓意'吉祥'"等
- **马年加持**：如"午时（11-13点）拜财神最灵验"、"'马上封侯'是传统吉祥图案，猴骑马背"等

### 3.2 交互设计

- 每张卡底部的"学一招"区域增加一个"再学一招"小按钮（刷新图标）
- 点击后随机切换到该卡的另一条知识，带淡入动画
- 使用 `useState` 为每张卡维护当前显示的 tip 索引
